# Advanced Neuro-Behavioral Digital Addiction Predictor

An AI-powered system that predicts digital addiction levels by analyzing user behavioral patterns and textual responses using Deep Learning and Natural Language Processing techniques.

## Project Overview

Digital addiction has become a growing concern due to excessive usage of smartphones, social media, and online platforms. This project aims to identify different levels of digital addiction by combining behavioral data analysis with semantic understanding of user responses.

The system leverages deep learning models, transformer-based embeddings, and explainable AI techniques to provide accurate and interpretable predictions.

## Features

* Digital addiction level prediction
* Behavioral pattern analysis
* Natural language processing of user responses
* Deep learning-based classification
* Real-time predictions through a web interface
* Model confidence scoring
* Explainable AI using SHAP visualizations
* Interactive Streamlit dashboard

## Installation

Clone the repository:

```bash
git clone https://github.com/akshaya2408/Digital-Addiction-Prediction.git
```

Navigate to the project directory:

```bash
cd Digital-Addiction-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Application

Launch the Streamlit dashboard:

```bash
streamlit run app.py
```

Open the local URL displayed in the terminal to access the application.
